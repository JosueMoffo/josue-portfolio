# Portfolio Josué Mbah Moffo

Portfolio professionnel développé avec **Astro** et **Tailwind CSS**.

##  Aperçu

-  Design Night Blue épuré et professionnel
-  Responsive (Mobile, Tablette, Desktop)
-  Performance optimale avec Astro
-  Sans icônes - Focus sur typographie et couleurs


###  Fichiers source
```
src/
├── layouts/
│   └── Layout.astro
└── pages/
    └── index.astro (combiner part1 + part2)
```

# Installer les dépendances
npm install

#  Lancer le serveur
npm run dev
```

Ouvrez **http://localhost:4321**


##  Technologies

- Astro 4.16
- Tailwind CSS 3.4
- TypeScript 5.3
- Google Fonts (Playfair Display, Inter, Fira Code)
